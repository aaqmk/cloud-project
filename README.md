# cloud-project

Этот проект создан в рамках курса по облачным технологиям. Он представляет собой веб-проект, разработанный с использованием HTML
В процессе обучения проект будет постепенно развиваться и дополняться новыми возможностями.
К концу курса в репозитории будет готовый веб-сайт, демонстрирующий полученные знания и навыки работы с облачными технологиями
